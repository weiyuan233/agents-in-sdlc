使用真实场景、完整应用程序和共享待办事项，跨软件开发生命周期探索 GitHub Copilot。你将迭代地规划变更、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。Tailspin Toys 是一家虚构公司，为以开发者为主题的棋盘游戏提供众筹服务。团队待办事项已作为 GitHub 议题创建，等待你接手。其中包括筛选和分页等功能，以及无障碍和编码规范等质量改进。

## 选择你的环境

GitHub Copilot 会在你工作的任何地方陪伴你。选择与你希望构建方式相匹配的环境。每个工作坊都有各自的准备步骤，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用代理式助手。使用 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright 模型上下文协议 (MCP)、Agent Merge，以及实用的斜杠命令。

### [GitHub Copilot app][app]

运行并行智能体会话、切换会话模式、协作处理画布，并在桌面应用中管理 GitHub 议题和拉取请求。

### [GitHub Copilot cloud agent][cloud]

将 GitHub 议题分配给异步云端智能体，指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
